## Explicit non-assumptions

- DenseNet-BC bottleneck width `4k`, transition compression `theta=0.5`, and floor rounding are paper/code specified.
- DenseNet-BC-100-12 has 16 dense units per block under the paper depth definition; this is derived directly from `L=6N+4`.
- Weight decay is coupled L2 applied to the single flattened parameter vector in the historical official runner; it is not a modern "exclude BN/bias" policy.
- `B-001` target selection is resolved by the human's exact 2026-08-16 approval; that approval is not an implementation assumption.
- Target approval permits Phase 1 architecture work. It is not the Phase 5 freeze and is not authorization to implement an optimizer or train on CIFAR.
